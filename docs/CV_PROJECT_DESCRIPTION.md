# FinQuality — CV / Portfolio Description

**Project:** Financial Data Analytics & Quality Dashboard

**Purpose:** Import synthetic financial transactions, identify data-quality issues, analyze income and expenses, and display insights in a web dashboard.

**Technology → functionality:**
- **Python:** CSV parsing, validation, and report generation.
- **Django REST Framework:** REST APIs for imports, transaction listing, quality metrics, analytics, and exports.
- **PostgreSQL:** Transaction storage and SQL aggregation.
- **React + TypeScript:** Interactive dashboard, date/category filters, upload and download actions.
- **Recharts:** Monthly cash-flow and category-spending visualizations.
- **Docker Compose:** Run the complete multi-service project locally.
- **Django tests:** Verify ingestion, duplicate handling, and analytics.

**Suggested CV bullet (after testing):** Developed a full-stack financial analytics dashboard using Django REST Framework, PostgreSQL, React, and TypeScript; built validated CSV ingestion, duplicate detection, SQL-based cash-flow summaries, interactive charts, and downloadable reports.

**Note:** Pandas is an optional installed dependency but is not currently used by the implemented data pipeline. Do not claim Pandas-powered ETL for this version.
